# 无测距按键起飞试验版

日期：2026-10-25。本目录是独立版本，原 `02主控源码`、`03遥控源码` 和先前固件保留。飞控已于 20:42:19 通过 Keil 烧录并校验成功；本版遥控器已于 20:48:58 通过 Keil 烧录并校验成功，两块板均为本版固件。

## 三个按键

| 按键 | 功能 |
| --- | --- |
| 按钮通道 3 / AUX3 | 自动解锁，保持姿态自稳，将总油门从 0 用约 3 秒缓升至默认 PWM 500，然后保持该总油门 |
| 按钮通道 4 / AUX4 | 请求人工接管；冻结当前总油门，实体油门与当前输出匹配连续 0.25 秒后，转为人工油门和姿态控制 |
| 按钮通道 2 / AUX2 | 收到有效指令后立即清零四路 PWM 并上锁，优先级高于同帧起飞或接管命令 |

上电不会自动解锁。按 3 前，油门最低，横滚/俯仰/偏航回中，机身接近水平（横滚、俯仰均在 ±10° 内）。不再要求测距或光流有效，也不再要求先执行摇杆解锁动作。已解锁且低油门的待机状态也可以按 3。

按 2 后不会因为按键保持、旧通道值或重复收到相同无线帧而自行重启；只有重新按一次 3、且启动条件满足，才会再次启动。原低油门加左偏航急停也保留；摇杆“低—高—低”解锁在本版关闭，防止覆盖按 2 的上锁状态。AUX1 不再启用定高/光流模式。

## 人工接管操作

按 4 后不是立即把最低油门切入电机。程序保持当前输出，等待油门匹配，以免从自动油门突然掉到零。默认自动油门 500 时，遥控通道油门大约在 **1667** 附近可匹配，允许差约 ±35 PWM，保持约 0.25 秒后进入人工模式。通道数值与实体摇杆位置取决于 ADC 标定。

新遥控固件在等待匹配时每约 700 ms 短鸣一次，接管完成后提示停止；无线反馈过期 500 ms 后也停止提示。若仍使用上一轮已烧录的遥控固件，3/4/2 的八通道映射相同，可发送这些按键指令，但没有新增的接管等待提示；射频兼容性尚未实测。

自动缓升或保持油门时，普通方向摇杆不改变横滚/俯仰目标，按 4 匹配接管后才恢复人工方向和偏航控制。按 2 在等待匹配期间仍立即生效。

## 本版的实际能力

**无测距意味着没有高度闭环。** 程序只能执行定时升油门和姿态自稳，不能知道是否已离地、离地多高，也不能保证 0.8 m 悬停或正常离地。默认 500 沿用供应商先前的悬停参考值，尚未按这台飞机的重量、电池、电机和桨实测；可能不足以起飞，也可能导致持续爬升。保持油门不等于保持高度。

本轮按用户要求先做按键流程：停止读取 0x62 测距/光流模块，停止高度 PID 和光流位置控制。BH1750 仍保留非阻塞照度采集与状态反馈，但本版不执行光源任务、四灯光源提示或三秒自动悬停锁控。

约 501 ms 未收到有效遥控帧时停机上锁；校验错误帧不会延长计时。机身倾角超过约 50° 时停机上锁。急停和失联停机在空中会失去升力，不能代替正常人工降落。

首次应拆桨检查按 3 的输出渐升、按 4 的油门匹配和按 2 的四路归零；未完成这些实机检查前，不应把本次编译与烧录校验视作飞行验证。
