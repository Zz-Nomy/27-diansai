# 按键 3 与光感任务入口修复

2026-10-25。已修改两端代码、完成模拟验证和完整 ARM 编译；用户当前未连接下载器，因此本次没有烧录。板上仍是前次烧录的版本。

## 已复现的问题与修改

1. 原程序仅在未解锁时处理 AUX3 起飞事件，导致已用摇杆解锁、油门最低时按 3 被忽略。现在地面已解锁和未解锁两种状态均检查起飞条件；油门、摇杆回中、地面高度、姿态与连续有效测距要求仍然保留。空中不会重新执行地面起飞。
2. 原光源任务仅允许 AUTO_HOVER 状态，手动起飞后完全不检测。现在手动起飞和自动起飞后，达到约 0.8 m±0.2 m、姿态和垂直速度稳定、有有效测距时，均可建立环境光基线并检测突增。无有效光流时可以检测并提示光源，但不能宣称保持位置。
3. 手动起飞后若要执行自动锁定 3 秒，须先用 AUX1 启用原定高/光流模式，并有有效高度、光流与照度反馈。进入锁定后固定当前高度和位置，屏蔽普通方向、偏航、油门及模式切换；紧急上锁、倾角与失联保护保留。手动姿态模式只提示光源，不会擅自启用位置控制或屏蔽遥控。锁定结束仍保留进入前的飞行模式。
4. 新增起飞请求编号、拒绝原因、AUX3 值、测距原始值、换算后高度及传感器有效标志的无线反馈，便于后续现场读取状态。

## 没有测距模块时

BH1750 仅测照度，不能提供高度。激光/光流模块未连接、损坏、地址错误或未输出有效高度时，程序拒绝一键起飞，按 3 不会启动电机；光源任务也不能确认有效悬停。不能用固定假高度绕过这项条件。

原配置仍按协议的厘米单位换算：`FLOW_HEIGHT_MM_PER_UNIT=10`。恢复模块后须对照尺子核实：0.8 m 处原始值约 80 时保留 10，约 800 时应设为 1。实际接线、有效高度与 BH1750 读数尚未验证。

## 遥控器新增拒绝提示（须更新两端固件）

按 3 后，若飞控收到指令但拒绝起飞，遥控器发出一组短鸣，每次 120 ms，间隔周期 350 ms；同一请求不会反复报警。

| 短鸣次数 | 原因 |
| --- | --- |
| 1 | 遥控数据不新鲜 |
| 2 | 油门未到底或方向/偏航未回中 |
| 3 | 测距无效或连续有效样本不足 |
| 4 | 地面高度或静止等待条件不满足 |
| 5 | 倾角超过允许范围 |

这组拒绝提示与光源报警不同：光源报警仍为每秒短鸣一次，共 3 次、每次 150 ms，四颗 LED 同步闪烁 3 秒。遥控链路断开时无法保证收到拒绝提示。
