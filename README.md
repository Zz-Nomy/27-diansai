## 构建与资料说明

使用Keil打开对应`.uvprojx`工程。现有AC6命令行构建方式和主机回归入口见[编译与验证说明](04_编译与验证/README.md)，独立试验版使用自己的构建脚本。Python脚本中的默认编译器路径是原开发机路径，换电脑后须按参数或脚本配置调整。

供应商源码包含GBK/GB18030编码；Git保留文件原始字节。仓库保留HEX、BIN、AXF、压缩包与验证记录，忽略对象文件、临时文件、主机测试EXE、本机界面配置和可重新下载的Keil设备安装包。设备包的官方下载地址、大小与SHA-256见[环境依赖](环境依赖.md)，本机原文件保留。历史JSON中的绝对路径与历史记录保持原样。
